# Backlog

The thirty ideas proposed in October 2026, all to be built, a round (one
pull request) at a time. Each feature is its own commit, with tests and
its strings in the eight languages. The status is kept up to date here.

Status: `todo`, `doing`, `done` (merged on `main`, with the PR number).
